STATUS DEL PROYECTO

Backend

Lista de requerimientos cumplidos

* Login
    * JWT
* Registro
    * Usuario con datos personales: nombre, correo, teléfono, dirección
    * Obtención de usuarios por correo, id o todos los usuarios
    * Obtención de roles del sistema
* Productos
    * Registro de nuevos productos
    * Obtención de productos todos o por id de producto
* Categoría de productos
    * Obtención de una categoría de productos por id o todas las categorías
* Carrito
    * Agregar un producto al carrito
    * Actualizar la catidad de productos por producto
    * Obtener carrito activo
    * Actualización de stock disponiblle si se agregan productos
* Productos del carrito
    * Registrar un producto en el carrito
    * Actualizar cantidades del producto en el carrito
    * Quitar un producto del carrito
    * Quitar todos los productos del carrito
* Ordenes
    * Agregar una orden
    * Descontar stock
    * Actualización de estado de la orden 
    * Obtener orden por id y status
    * Obtener todas mis ordenes por estatus
* Productos de la orden
    * Agregar un conjunto de productos a la orden
